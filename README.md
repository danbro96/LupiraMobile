# LupiraMtgMobile

React Native (Expo + TypeScript) client for [LupiraMtgApi](https://github.com/danbro96/LupiraMtgApi) (`https://mtg-api.lupira.com`) — Magic: The Gathering card search, camera card scanning, and collections.

App: **Lupira MTG** · package `com.lupira.mtg` · scheme `lupiramtg` · EAS project `lupiramtg` (owner `danbro96`).

## Features

| Tab | What |
|---|---|
| Cards | Search the Scryfall-backed catalog; card + printing detail. |
| Scan | On-device card detection (VisionCamera + fast-opencv), crop, upload to `/scans`; pick matches into a selection, file into a collection. |
| Collections | List/detail of the user's collections. |

Settings (gear in every tab header, pushed over the tabs): account + sign-out, scan tuning, decision log, API endpoint.

## Auth

Authentik OIDC — authorization code + PKCE, public client, the only sign-on. Config in `src/auth/oidcConfig.ts`:

| | |
|---|---|
| Issuer | `https://auth.lupira.com/application/o/lupira-mtg` |
| Client ID / API audience | `lupira-mtg` |
| Redirect URI | `lupiramtg://oauthredirect` (must be registered, strict, on the Authentik provider) |
| Scopes | `openid email profile groups offline_access` |

Admin = `groups` claim. Tokens live in `expo-secure-store`; refreshed on launch and on 401. Provider definition: DevOps `Identity/authentik/blueprints/40-apps-lupira-mtg.yaml`.

## Running locally

Needs a **dev build** (native modules + custom scheme) — Expo Go won't work.

```sh
npm install
npm run android          # expo run:android (local prebuild + install)
# or: eas build --profile development --platform android
npx expo start           # Metro for the installed dev client
```

API base URL defaults to `https://mtg-api.lupira.com` (`src/config.ts`); override it on the login screen → **Advanced** (also shows the redirect URI in use).

## UI

react-native-paper 5 (MD3), light/dark following the system — the same kit as the other Lupira mobile apps (Tasks, Cal, Assistant). `src/ui/theme/tokens/` is a copy of the estate token core; check drift with DevOps `Guides/check-token-drift.sh`. Icons = MaterialIcons via `src/ui/icons.ts` (`ICONS.x`, never bare names — `npm test` fails on unknown glyphs). The camera HUD stays fixed-dark over the feed.

Card symbols (mana, `{T}`, `{Q}`, hybrid, Phyrexian, …) come from [Scryfall's symbology](https://scryfall.com/docs/api/card-symbols), pre-converted to react-native-svg node trees in `src/ui/symbols/generated/` (`npm run fetch:symbols` to refresh). `SymbolText` renders rules text with inline symbols and italic reminder text; `ManaCost` renders a cost. Symbols are © Wizards of the Coast, used under the [Fan Content Policy](https://company.wizards.com/en/legal/fancontentpolicy).

## API client

Generated by Orval (react-query hooks, `tags-split`) into `src/api/generated/` from `backend-openapi.json`; all calls go through `src/api/mutator.ts` (auth header, live base URL, 401 refresh).

```sh
npm run regen:api        # copy ../LupiraMtgApi/openapi/LupiraMtgApi.json, then orval
npm run fetch:openapi -- https://mtg-api.lupira.com/openapi/v1.json   # or from a URL
```

## Builds

EAS profiles (`eas.json`): `development` (dev client, APK), `preview` (internal APK), `production` (AAB, auto-increment). OTA via `expo-updates`, `runtimeVersion` = fingerprint. Errors/replays → Sentry (`brostrom/lupira-mtg`).
